# Asset sources

All images are bundled to avoid runtime network dependencies in the main application.

- Manrope variable font: [Google Fonts / Manrope](https://github.com/google/fonts/tree/main/ofl/manrope). SIL Open Font License included in `assets/fonts/OFL.txt`.
- Campus photograph: [Unsplash image source](https://images.unsplash.com/photo-1541339907198-e08756dedf3f).
- Development photograph: [Unsplash image source](https://images.unsplash.com/photo-1498050108023-c5249f4df085).
- Design photograph: [Unsplash image source](https://images.unsplash.com/photo-1558655146-9f40138edfeb).
- Data photograph: [Unsplash image source](https://images.unsplash.com/photo-1551288049-bebda4e38f71).
- Business photograph: [Unsplash image source](https://images.unsplash.com/photo-1522071820081-009f0129c71c).
- Sample portraits: [Random User Generator](https://randomuser.me/), sample portrait images only. The names, addresses and academic information in CAMPUSLY are invented and do not describe the pictured people.
- Launcher icons: code-drawn CAMPUSLY graduation-cap mark, created for this project.

The avatar laboratory uses `https://randomuser.me/api/portraits/women/68.jpg` to demonstrate an actual network image; initials remain visible while loading or if the request fails.
